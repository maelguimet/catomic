Catomic Beta 0.2 is Catomic getting out of its own way: the editor core is much
faster, Project mode is gone, and the built-in AI stack has been deleted rather
than left dormant behind a flag.

## FAST

The 17-PR performance pass was measured by the Catobench suite across 13
workloads, using five alternating runs of the pre-pass commit
[`2c51715`](https://github.com/maelguimet/catomic/commit/2c5171506bb00783982723a52c51fd0d1b8f69b6)
and the completed pass
[`3afc727`](https://github.com/maelguimet/catomic/commit/3afc7275f4204d1ea3eb584251e216fcd367ad51).

- **6.72× geometric-mean speedup**
- **2,229× faster** cursor motion on long Unicode lines
- **116× faster** fragmented PieceTable edits
- **91× faster** start-of-document line-index edits
- **76× faster** batched replacements
- **2.46–3.94× faster** rendering
- **2.33× faster** newline-dense Markdown preview with **58.6% lower peak RSS**
- **1.53× faster** repeated paged viewports

This came from bounded structural work, not decorative microbenchmarking:
PieceTable edits now mutate local runs, line-index changes are block-local,
multi-range replacements are batched, Unicode coordinate lookup uses sparse
checkpoints, large searches stream cooperatively, preview storage is sparse,
and the terminal retains published rows and redraws only actual damage.

The benchmark also preserves the losses. Synchronous search is 2.21× slower,
retained-page editing is 7.1% slower, and the paste/delete workload has higher
peak time and RSS. Streamed-search responsiveness and bounded-retention
invariants passed; those regressions are not being airbrushed into “up to”
marketing soup.

## What Catomic is now

- A Linux-first, modeless terminal editor with familiar selection, mouse,
  search/replace, goto-line, undo/redo, multiple buffers, and GUI-style
  shortcuts.
- Unicode-correct cursor movement and layout for grapheme clusters, combining
  marks, wide characters, emoji sequences, and tabs.
- Editable large-file paging without loading a monster file into one giant
  string.
- Atomic saves, conflict detection, external-change highlighting, explicit
  overwrite/reload confirmation, and optional `.catnap` recovery.
- Viewport-only Markdown, Rust, Python, and JSON highlighting plus a read-only
  Markdown preview.
- Explicit, cancellable `F4` linting attached to the active file, without a
  workspace service or Problems panel.
- A local fuzzy emoji picker, configurable keybindings and themes, named
  external commands and lifecycle hooks, Linux desktop/OSC 52 clipboard
  support, and a touch-first Termux interface.

Ordinary editor construction, typing, and rendering do not scan a repository,
start configured processes, read credentials, or contact a network service.
The explicit updater is the documented exception.

## What was removed

- The Plain/Project mode split and its persistent project session.
- Repository discovery, cached project-path completion, project file picker,
  Git-backed project plumbing, cross-file diagnostics navigation, and the
  Problems-style diagnostics view.
- Model-backed autocomplete and the magic `explain` answer mode.
- The model picker, provider presets/discovery, prompt construction, context
  broker, request queue, HTTP model client, model change marks, AI preview/apply
  flow, current-file model commands, and repository-aware model workflows.
- The related configuration, dependencies, tests, docs, and dead compatibility
  paths. This is a source-level deletion with a regression gate preventing the
  built-in AI runtime from creeping back in.

Local current-buffer completion remains. Linting remains as one explicit,
bounded editor action. Trusted user-configured commands and hooks remain for
people who want automation without making the editor pretend to be an IDE.

## Install

The release assets include a ready-to-run x86-64 Linux binary; Rust is not
required:

```sh
version=0.2.0-beta.1
curl -fLO "https://github.com/maelguimet/catomic/releases/download/v$version/catomic-x86_64-unknown-linux-gnu"
curl -fLO "https://github.com/maelguimet/catomic/releases/download/v$version/catomic-x86_64-unknown-linux-gnu.sha256"
sha256sum --check --strict catomic-x86_64-unknown-linux-gnu.sha256
install -Dm755 catomic-x86_64-unknown-linux-gnu "$HOME/.local/bin/catomic"
```

Packaged Cargo source, full checksums, toolchain records, provenance, and
fresh-download verification evidence are attached for anyone who enjoys
auditing their text editor more than using it.
