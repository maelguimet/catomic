Catomic Beta 0.2 is Catomic getting out of its own way: the editor core is much
faster, Project mode is gone, and the built-in AI stack has been deleted rather
than left dormant behind a flag.

This `beta.2` tag corrects the managed publication workflow after the `beta.1`
tag stopped before producing a GitHub release or any downloadable assets. The
editor source includes the same Beta 0.2 feature set plus the verified
Ctrl+Backspace/Alt+Backspace word deletion and restored Ctrl+H help defaults.

## Highlights

- A 6.72× geometric-mean speedup across the 13-workload Catobench suite, with
  the full method and preserved regressions in the
  [Beta 0.2 performance report](0.2.0-beta.1.md#fast).
- Familiar modeless editing, Unicode-correct movement and layout, multiple
  buffers, search/replace, atomic saves, conflict detection, and catnap
  recovery.
- Editable large-file paging, viewport-only syntax highlighting, Markdown
  preview, explicit linting, configurable keybindings/themes, emoji picker,
  external commands/hooks, and Linux clipboard support.
- Project mode and the entire built-in model/provider runtime were removed at
  the source level and remain guarded by static regression checks.

## Install

```sh
version=0.2.0-beta.2
curl -fLO "https://github.com/maelguimet/catomic/releases/download/v$version/catomic-x86_64-unknown-linux-gnu"
curl -fLO "https://github.com/maelguimet/catomic/releases/download/v$version/catomic-x86_64-unknown-linux-gnu.sha256"
sha256sum --check --strict catomic-x86_64-unknown-linux-gnu.sha256
install -Dm755 catomic-x86_64-unknown-linux-gnu "$HOME/.local/bin/catomic"
```

Packaged Cargo source, checksums, toolchain records, provenance, and
fresh-download verification evidence are attached to the managed release.
