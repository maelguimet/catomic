Catomic 0.3 is the first stable release. It builds on the Beta 0.2 editor core
with link handling, piped-input editing, a review-first replace workflow, and a
long run of terminal-safety, file-safety, and Unicode fixes found while using
the beta every day.

## Highlights

- Links: detected URLs are coloured, underline on pointer hover, and open with
  Ctrl+click. `[view] link_hover = false` turns off any-motion mouse tracking
  for SSH and multiplexer sessions while keeping clicks, wheel, and drags.
- `catomic -` edits explicitly piped stdin as an unsaved buffer.
- Replace reviews each candidate, so you can accept matches one at a time or
  all at once in a single workflow.
- Prompts edit at a grapheme caret and complete explicit file paths.
- Ctrl+H help lists the essential view, editing, and paging commands, plus
  every palette command taken from the prompt parser's catalog.

## Safety and correctness

- Terminal sessions:
  - Raw mode is entered before any reporting mode and released only after
    every report is disabled and late input is discarded. Mouse, focus, and
    Kitty key-release bytes no longer leak into the shell after Ctrl+Q.
  - Disconnected terminal input is handled safely.
  - A panic on a worker thread no longer tears down the live session.
- External commands, linters, hooks, clipboard helpers, and the link opener run
  in their own session and cannot draw on or read from the editor's terminal.
- Paged large files:
  - Same-length rewrites with a restored mtime are detected, including those in
    the same ctime clock tick as the open.
  - Hard-linked paged saves preserve the original bytes.
  - Sessions survive backing drift.
- Saving and recovery:
  - Named files are recoverable before their first save.
  - Unresolved crash recovery survives autosave.
  - Long save targets get bounded staging names.
  - A leading content U+FEFF is preserved in BOM text.
- Unicode and layout:
  - Navigation, page movement, edits, Tab stops, End on wrapped wide
    graphemes, and soft wrap at whitespace all respect grapheme and
    visual-column boundaries.
  - Help reflows cleanly when the terminal is resized or narrow.
- A search or go-to-line worker that stops without a result now reports an
  error instead of searching forever.
- Dependencies: `rustls` is updated for RUSTSEC-2026-0285.

## Behaviour changes

- Editor sessions (`catomic`, `catomic FILE`, `catomic config edit`) refuse to
  start when stdout is not a terminal, with
  `catomic requires terminal output on stdout`. `--version`, `--help`, and
  non-editor `config` subcommands still work when redirected.
- External commands that need an interactive prompt on the terminal (for
  example an ssh password prompt) now fail instead of drawing over the editor.
- Quitting waits for terminal input to go quiet, which adds 50–250 ms.
- Opening or reloading a large paged file that changed within the last clock
  tick waits once for that tick to pass. On filesystems with whole-second
  timestamps, this can take up to about two seconds. Saves never wait.

## Install

```sh
version=0.3.0
curl -fLO "https://github.com/maelguimet/catomic/releases/download/v$version/catomic-x86_64-unknown-linux-gnu"
curl -fLO "https://github.com/maelguimet/catomic/releases/download/v$version/catomic-x86_64-unknown-linux-gnu.sha256"
sha256sum --check --strict catomic-x86_64-unknown-linux-gnu.sha256
install -Dm755 catomic-x86_64-unknown-linux-gnu "$HOME/.local/bin/catomic"
```

Packaged Cargo source, checksums, toolchain records, provenance, and
fresh-download verification evidence are attached to the managed release.
